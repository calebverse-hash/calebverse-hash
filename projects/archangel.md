# Project Archangel — Search-and-Rescue Drone/Rover Concept

**Role:** Independent initial concept and systems planning  
**Stage:** Concept exploration; later set aside when priorities changed

## Idea

I explored an indoor search-and-rescue concept involving communication between an unmanned drone and ground rover. After faculty feedback, the potential engineering focus shifted from mapping toward **reliable communication between vehicles**.

## Work I did

- Considered mission objectives, candidate sensors and possible drone/rover roles.
- Compared high-level communication and autonomy requirements.
- Began setting up a local development environment and installed PX4/Gazebo-related tools.
- Thought through potential project scope, component options, sponsorship and collaboration.

## What was *not* completed

I did **not** complete a working simulation, build a prototype, implement drone–rover communication, or gain meaningful operating proficiency with PX4 or Gazebo. Software installation should not be mistaken for hands-on tool experience.

## What I learned

Early-stage engineering requires clear requirements, feasible scope, prioritization and realistic assessment of resources. This project helped me ask better questions about what to build versus buy, what could be demonstrated, and how to structure a team project.

The original Archangel repository remains private. This write-up describes concept development, not a finished autonomous system.
